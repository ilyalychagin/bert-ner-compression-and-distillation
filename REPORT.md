## Датасет

Named Entity Recognition – это задача классификации токенов по классам сущностей. В CoNLL-2003 для именования сущностей используется маркировка **BIO** (Beginning, Inside, Outside), в которой метки означают следующее:

- *B-{метка}* – начало сущности *{метка}*
- *I-{метка}* – продолжнение сущности *{метка}*
- *O* – не сущность

Всего в датасете есть 9 разных меток.
- O – слову не соответствует ни одна сущность.
- B-PER/I-PER – слово или набор слов соответствует определенному _человеку_.
- B-ORG/I-ORG – слово или набор слов соответствует определенной _организации_.
- B-LOC/I-LOC – слово или набор слов соответствует определенной _локации_.
- B-MISC/I-MISC – слово или набор слов соответствует сущности, которая не относится ни к одной из предыдущих.

## Предобработка

В качестве токенизатора взята модель "bert-base-cased", которая учитывает регистр слов. 
В папке dataset написан функционал для предобработки датасета. В `tokenize_dataset` текст токенизируется, затем теги выравниваются по получившимся частям слов с помощью `align_labels_with_tokens`. Первый сабтокен получает исходную метку слова. Для последующих сабтокенов метка `B-*` заменяется на соответствующую `I-*`, а метки `I-*` и `O` сохраняются. Токены `[CLS]`, `[SEP]` и позиции паддинга получают метку `-100`.

## Предобученный BERT

В качестве базовой модели взят `bert-base-cased`. В файле `finetune_bert.py` реализован скрипт для запуска дообучения на задаче NER. Параметры обучения: 

- оптимизатор — AdamW, `weight_decay=0.01`.
- функция потерь — кросс-энтропия.
- размер батча — 64.
- максимальная длина — 512 токенов.
- scheduler — `ReduceLROnPlateau` с параметрами `factor=0.5`, `patience=1`.
- число эпох — 10.
- начальные learning rate — `1e-5`, `3e-5` и `5e-5`.

Для оценки качества использовалась F1 мера с микро-усреднением. Лучшие результаты получились при `lr = 5e-5`. Чекпоинт с 8-й эпохи показал 0,94 Val F1 и 0,90 Test F1, достигнув порога 0,9 из задания. Обучение заняло ~10 минут на V100. Эту модель я использовал как учителя в следующих экспериментах.

## Эксперименты с уменьшением модели

### Факторизация матрицы эмбеддингов 

Матрица эмбеддингов раскладывается в произведении двух других: $W = U V$. Кол-во параметров в исходной матрице `vocab_size x hidden_size`. Разложение же позволяет сократить кол-во параметров до `vocab_size x factor_dim + factor_dim x hidden_size`. При этом инициализировать матрицы $U$ и $V$ можно через SVD разложение исходной матрицы. $U$ определяется через произведение $r$ наибольших сингулярных чисел и соответствующих им левых сингулярных векторов. $V$ - через соответствующие $r$ правых сингулярных векторов. Это даёт хорошее начальное приближение.

Соответствующий функционал реализован в `factorization_emb.py`.  Создан кастомный слой `FactorizationEmbedding` для получения эмбеддингов из матрицы эмбеддингов. В `__init__` реализован функционал для инициализации описанный выше. В `forward` для входных индексов токенов возвращаются соответствующие им вектора. При этом нет необходимости каждый раз заново строить всю матрицу $W = U V$. Это эквивалентно взятию соответствующих строк из матрицы $U$, и последующего домножения получившейся из строк матрицы на $V$. Класс `FactorizedBertForTokenClassification` является просто обёрткой над `BertForTokenClassification`, который заменяет слой для получения эмбеддингов на кастомный `FactorizedBertForTokenClassification` и добавляет статический метод `from_teacher`, поддерживающий инициализацию факторизованной матрицы эмбеддингов из учителя. Код для запуска обучения находится в `factorization_bert.py`

Был произведён один запуск с `factor_dim = 64`. За те же 10 эпох получилось достичь качества 0.875 Test F1 и сократить кол-во параметров с 107726601 до 87362569. Размер слоя эмбеддингов уменьшился с 22 268 928 до 1 904 896.

### Шеринг весов 

В методе предлагается шерить веса между слоями. Идея взята из модификации BERT [ALBERT](https://arxiv.org/pdf/1909.11942). Функционал реализован в `shared_bert_encoder.py`. Написана обёртка поверх бертовского энкодера. Код, реализующий эту идею, представлен в `forward`. Блоки трансформера переиспользуются по циклу для получения новых скрытых состояний. Например, если в BERT 4 трансформенных блока, а кол-во применений слоёв равно 12, то каждый трансформенный блок применяется на слоях i, i + 4, i + 8. Код, запускающий обучение и подменяющий исходный энкодер на кастомный, реализован в `sharing.py`. 

Было произведено 4 запуска. Во всех из них взят лишь один блок энкодера, который шерится между всеми 12 слоями. Параметры модели:

- `hidden_size: int = 1024`
- `intermediate_size: int = 5120`
- `num_hidden_layers: int = 1`
- `num_attention_heads: int = 16`
- `num_shared_steps: int = 12`

Кол-во параметров 19074569

Результаты:

| Learning rate | Учитель | Лучшая эпоха | Val loss | Test loss | Val F1 | Test F1 |
|---:|:---:|---:|---:|---:|---:|---:|
| `9e-5` | Нет | 84 | 0.4040 | 0.6324 | 0.8009 | 0.7314 |
| `9e-5` | Да | 81 | 0.3362 | 0.5305 | 0.8030 | 0.7319 |
| `2e-4` | Нет | 97 | 0.3900 | 0.6317 | 0.8068 | 0.7337 |
| `2e-4` | Да | 79 | 0.3465 | 0.5751 | 0.8097 | 0.7296 |

Результаты сопоставимы с обычной дистилляцией. У модели с шерингом 19,07 млн параметров, у обычного ученика — 17,92 млн. Время обучения выросло с ~50 до ~140 минут (~160 минут с учителем). У обычного ученика последовательность проходит через пять блоков, у модели с шерингом один широкий блок применяется 12 раз.

При этом добавление в обучение учителя почти не влияет на результаты метрики F1. Но при этом loss уменьшается. Например при `lr=9e-5` лосс уменьшился с 0.6324 до 0.5305

### Шеринг + дообучение с LoRA

В `shared_bert_encoder.py` также поддерживается функционал для обучения с LoRA. В [статье](https://arxiv.org/pdf/2410.20672) предложено добавлять отдельный LoRA-адаптер для каждого применения общего блока. Добавлен статический метод `from_teacher`. Во-первых, он позволяет инициализировать трансформерные блоки через среднее значений весов учителя по соответствующим слоям. При четырёх общих блоках и 12 применениях параметры блока $i$ вычисляются как среднее по слоям учителя $i$, $i+4$ и $i+8$. Во-вторых, реализована инициализация LoRA-адаптеров по следующей схеме:

$U_r, \Sigma_r, V_r^T = \text{Truncated SVD} (W_l - W'_{((l-1)\text{mod} L / B) + 1}; r), l \in [1, L]$

$A = V_r^T$

$B = U_r \Sigma_r$

То есть пытаемся с помощью LoRA добавок минимизировать разницу между исходной матрицей весов предобученного BERT и матрицей весов ученика.

Во время обучения выход линейного слоя с LoRA-адаптером вычисляется как:

$\mathrm{output} = (W' + BA)x + b$

После обучения для каждого применения блока можно объединить $W'$ с его добавкой $BA$. При таком слиянии на каждой глубине появляется своя плотная матрица, и эти проекции теряют экономию параметров от шеринга.

Было проведено 3 запуска. Параметры модели в каждом из них:

- `hidden_size = 768`
- `intermediate_size = 3072`
- `num_hidden_layers = 2`
- `num_attention_heads = 12`
- `num_shared = 12`
- `lora_rank = 8`

Общее кол-во параметров c LoRA - 17810953, без LoRA - 16483849. LoRA-адаптеры устанавливались на проекционные матрицы в Attention и на линейные слои в FFN. Результаты эксперимнтов:

|---:|:---:|:---:|---:|---:|---:|---:|---:|
| `2e-4` | Да | Нет | 87 | 0.2201 | 0.3490 | 0.8837 | 0.8321 |
| `2e-4` | Да | Да | 89 | 0.1906 | 0.3308 | 0.8944 | 0.8421 |

Обучение заняло соотственно ~98 минут, ~105 минут, ~81 минуту. Связка из обучения с учителем и LoRA-адаптерами даёт лучшее качество и наименьший loss, но при этом всё-таки незначительно обгоняет все остальные варианты по целевой метрики F1. Обычный шеринг с инициализацией слоёв через среднее также демонстрирует неплохие результаты.

### Приближение промежуточных слоёв

Помимо приближения выходов моделей ученика и учителя добавляется приближение выходов промежуточных слоёв. В `train.py` дистилляция промежуточных слоёв реализована по мотивам [статьи](https://www.researchgate.net/publication/375758425_Knowledge_Distillation_Scheme_for_Named_Entity_Recognition_Model_Based_on_BERT). Из модели берутся все hidden states. Для получения матрицы скоров внимания скрытые представления проходят через линейные проекции для key и query и затем перемножаются как в обычном Attention:

$\text{scores} = \frac{Q K^T}{\sqrt{d}}$

В итоговый лосс добавляются MSE по выходам блоков и по скорам внимания. Слои ученика с 1-го по 6-й сопоставляются со слоями учителя 2, 4, 6, 8, 10 и 12. Для слоя $i$ обозначим выход блока через $H_i$, а матрицу скоров внимания через $S_i$. MSE по выходам учитывает токены без паддинга, MSE по скорам — пары таких токенов.

$\text{attn\_loss} = \sum_{i=1}^{6} \text{MSE}(S_i^{\mathrm{student}}, S_{2i}^{\mathrm{teacher}})$

$\text{hidden\_loss} = \sum_{i=1}^{6} \text{MSE}(H_i^{\mathrm{student}} W_h, H_{2i}^{\mathrm{teacher}})$

Стоит заметить, что для hidden_loss также добавляется проекционная обучаемая матрица $W_h$, чтобы привести размерность выходов ученика к размерности учителя.

Было проведено 3 эксперимента с параметрами модели:

- `hidden_size_student = 480`
- `intermediate_size_student = 2048`
- `num_hidden_layers_student = 6`
- `num_attention_heads_student = 12`

Общее кол-во параметров - 19502761.

Результаты:

|---:|---:|---:|---:|---:|---:|
| `9e-5` | 67 | 0.2952 | 0.4748 | 0.8497 | 0.7805 |
| `2e-4` | 58 | 0.2585 | 0.4088 | 0.8721 | 0.8151 |
